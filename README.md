# 🐍 Portfólio: Python para Data Science (SENAI)

Este repositório contém os projetos práticos e estudos desenvolvidos durante o curso de **Aperfeiçoamento em Programação em Python para Data Science** do SENAI (2025).

## 📂 Estrutura do Projeto

* **Python & Pandas:** Scripts para análise exploratória de dados (EDA), limpeza de dados e visualização (Matplotlib).
    * *Destaque:* Análise do mercado imobiliário de SP e correlações estatísticas.
* **PySpark:** Introdução ao processamento de Big Data, manipulação de DataFrames e SparkSQL.
    * *Destaque:* Análise do dataset de filmes (LetterBoxed).
* **SQL:** Queries avançadas para banco de dados relacional.
    * *Conceitos:* Joins, Subqueries, CTEs (Common Table Expressions) e Window Functions.

## 🛠 Tecnologias Utilizadas
* Python 3.x
* Pandas & NumPy
* Matplotlib
* PySpark
* SQL Server / T-SQL

## 📄 Sobre o Curso
Curso focado em técnicas de coleta, limpeza, organização e transformação de dados, totalizando 60 horas de imersão prática.
